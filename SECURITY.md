# Security Policy

## Supported Versions

Only the latest version of `@yildizpay/http-adapter` receives security fixes.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities by emailing **mevlutkural35@gmail.com** with the subject line `[SECURITY] @yildizpay/http-adapter`.

Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The affected version(s)

You can expect an acknowledgement within **48 hours** and a resolution or mitigation plan within **7 days** depending on severity.

Once the vulnerability is resolved, a patch will be released and the issue will be publicly disclosed.
